## 🧪 Generated Test Format

Tests are generated in proper Endorphin format:

```javascript
// QE-015: User Registration Flow
// Description: Test complete user registration process
// Priority: High
// Tags: registration, signup, recorded
// Generated by Test Recorder: QE-015-1703234567890

export const QE_015 = {
  "id": "QE-015",
  "name": "User Registration Flow",
  "description": "Test complete user registration process", 
  "priority": "High",
  "tags": ["registration", "signup", "recorded"],
  "site": "https://myapp.com",
  "testData": { "email": "test@example.com" },
  "task": "Navigate to https://myapp.com Click login button Fill email field STOP - test completed.",
  "recordingId": "QE-015-1703234567890",
  "recordedSteps": 3
};
```
